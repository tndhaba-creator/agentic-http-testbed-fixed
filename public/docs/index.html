API Docs

We support both web browsing and API access.

  • List products: GET /api/products?page=1&limit=10&q=widget
  • Search: GET /api/search?q=widget
  • Product detail: GET /api/product/[id] (HTML)
  • Book: POST /api/book?product_id=ID&email=you@example.com
  • Status: GET /api/status?id=BK-123456

Schema: /openapi.json

Note: /api/book requires POST. Status is idempotent.
